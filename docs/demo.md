# 演示

线上地址：**https://codepilot-ai-chi.vercel.app**

配套录屏：`docs/demo.mp4`（49 秒，1280×800，无音频）。录的是线上环境，不是本地。

## 1. 演示前 10 分钟检查

| 检查 | 动作 | 通过标准 |
|---|---|---|
| 网络 | 打开线上地址 | 能加载（国内需代理，见下） |

## 2. 三分钟演示脚本

### 0:00–0:20 定位（首页）

- 停在首页，念标题：**「从一句话到一段代码，中间不用换工具」**
- 指四类任务：生成 / 解释 / 调试 / 重构，**共用同一套输入与结果结构**
- 指四条事实：8 种语言、不执行用户代码、密钥只在服务端、账号隔离
- 点「打开工作台」

### 0:20–0:40 登录（体现账号体系）

- 在 `/login` 输入账号密码
- 一句话说明：会话存在 HttpOnly cookie 里，服务端每次 `getUser()` 真校验，不是只看 cookie 有没有

### 0:40–1:50 生成 + 流式（核心）

- 输入：`写一个 JavaScript 函数，把日期格式化成 YYYY-MM-DD`
- 点「生成代码」
- **重点讲这一句**：注意文字是**一段一段**出现的，不是等几秒整块蹦出来；Network 面板里能看到 `/api/ai/generate` 的 `text/event-stream`
- 生成完指元信息行：`qwen-plus · 11.7 s · 679 tokens`——这是模型返回的真实用量，不是估算
- 指右侧「代码」面板：从回答里自动抽出的代码块，可直接复制

### 1:50–2:10 保存片段（资产化）

- 点回答下方的「保存片段」
- 标题改成 `格式化日期 formatDate`，保存
- 点侧栏「代码片段」→ 列表里能看到刚保存的卡片，支持搜索与语言筛选
- 一句话：会话是过程，片段是结果；片段可以跨会话复用

### 2:10–2:30 设置（偏好与模型参数）

- 进 `/settings`
- 指「账号」区：默认语言存数据库，换设备也还在
- 指「模型调用」：温度与流式开关随请求下发，服务端会**重新校验**，因为 localStorage 用户可以改

### 2:30–3:00 数据隔离（差异化亮点）

- 退出登录，用第二个账号登录（`e2e-b@codepilot.local`）
- 直接访问第一个账号的会话 URL → **404**
- 说明两点：
  1. 不是应用层判断"这不是你的"，而是数据库 RLS 让这行**查不到**，代码自然落到 404 分支；
  2. 返回 404 而不是 403，是为了不泄露"这个 ID 存在"。

## 3. 讲清楚三个技术决策（面试版，各 60 秒）

1. **RLS 是边界，不是应用代码**
   请求路径上只用 publishable key + 用户 token，secret key 一次都不出现。即使某个仓储函数漏了 owner 过滤，数据库也不会把别人的行返回。`messages` 表甚至没有 `owner_id`，四类策略统一用 `exists` 校验父会话归属。

2. **历史由服务端管，客户端只说"哪一轮"**
   客户端只传 `conversationId`，历史从数据库读，再按 10 条 / 单条 4000 字 / 总量 24000 字裁剪。这样刷新、换设备、伪造请求都不会让上下文失真。
   **主动说取舍**：字符预算不是 token 预算，只是成本护栏。

3. **流式协议只有一份**
   四个任务共用 `meta / delta / done / error` 四种 SSE 事件。关掉流式后上游改成非流式，但对浏览器仍是"一个 delta + 一个 done"，前端不需要分叉。

## 4. 失败预案

| 现象 | 原因 | 现场处理 |
|---|---|---|
| 页面打不开、超时 | 代理没开 / Vercel 被墙 | 开代理，或改用热点 + 代理 |
| `503 CONFIG` | Vercel 环境变量缺失 | 打开 `/api/health` 看 `missing` 字段 |
| 首字很慢（>10s） | 模型冷启动 | 等一次，第二次会快；别反复点 |
| 429 | 限流（默认 10 次/分钟） | 等 1 分钟，或说明"限流按 IP、进程内计数"这个已知限制 |
| 输出整段出现 | 网络中间层缓冲 | 说明代码已设 `no-transform` 与 `X-Accel-Buffering`，本地/线上实测均流式；现场网络问题 |

## 5. 录屏是怎么来的

`docs/demo.mp4` 由 Playwright 在**线上环境**真实操作录制（Edge headless，1280×800），流程为：首页 → 登录 → 生成 → 深色主题 → 保存片段 → 片段页 → 设置页。录制后转 H.264（CRF 28），49 秒 / 696 KB。

重录方式：登录态与操作脚本不进入版本库（涉及测试账号密码）；如需重录，按第 2 节脚本手工操作，或用 `e2e/` 里的 helper 自己写一段 Playwright 录制。
